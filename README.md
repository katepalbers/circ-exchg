# circ-exchg

This site is built with [Jekyll](https://jekyllrb.com), a static site generator, and hosted on [GitHub](https://www.github.com/katepalbers/circ-exchg) pages. The fonts used are [Calendas](https://calendasplus.com) for the main text, [Cooper Hewitt](https://www.cooperhewitt.org/open-source-at-cooper-hewitt/cooper-hewitt-the-typeface-by-chester-jenkins/) for the headlines and captions, and [Font Awesome](https://fortawesome.github.io/) for the icons. The PDF download is created locally with [Prince XML](https://www.princexml.com/).
